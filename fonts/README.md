# fonts/ — 그림 생성용 한글 글꼴

`NotoSansCJKkr-Regular.otf`·`NotoSansCJKkr-Bold.otf`: Noto Sans CJK KR (SIL Open Font License 1.1)을 한글 음절 11,172자·자모·라틴·그리스 문자·원문자(①②③)·수학 기호·화살표·도형 등 그림에 쓰는 범위로 서브셋한 파일(각 약 1.8∼1.9 MB). 그림을 그리는 스크립트 전부(`v7_final_10020/charts/`, 페르소나·실루엣 게이트·시계열 그림)가 이 두 파일을 먼저 등록해 쓰므로 시스템에 한글 글꼴이 없어도 같은 그림이 나온다(`KFONT_PATH`로 다른 글꼴 지정 가능). 원본: https://github.com/notofonts/noto-cjk
