# 팬덤결속 지수(Fandom Cohesion Index) — 최종 코퍼스 10,020건 판

> 입력: 최종 원본 `data/v7_final/fandom_cohesion_index_v7.json`(10,020건). 실행 노트북: `fandom_cohesion_index_v7.ipynb`.

## 지수 정의(원문 `methodology`)

원문 문자열 매칭, 광고 지수와 같은 2단계 설계 원칙. (1) 5개 결속 활동 유형 키워드 중 하나라도 매칭되면 결속 불릿(멀티라벨),
(2) **D(기부·후원)는 그 자체로는 신호가 아니며** `팬클럽/팬카페/팬덤/팬들/함께/자발적/정회원/회원` 중 하나가 같은 문장에 공존해야만 카운트
(아티스트 개인 선행과 팬덤 주도 기부를 구분하는 정밀도 게이트). LDA 토픽·K→M→F 재군집화를 참조하지 않는 독립 보조지표.

| 유형 | 건수 (10,020건) |
|---|---:|
| A 공식 팬클럽·회원제 | 480 |
| D 기부·후원 캠페인(팬덤 주도) | 198 |
| B 팬카페·온라인 커뮤니티 | 190 |
| E 오프라인 결집·이벤트 | 173 |
| C 팬덤 정체성·문화 | 122 |

코퍼스 합계: 결속 불릿 923건(9.2%), 99개 팬덤에 1건 이상. D 게이트 정밀도 검증: 기부·후원류 언급 364건 중 166건(45.6%) 제외.

## 노트북이 확인한 것

1. **무결성** — 근거문장 수 = 코퍼스 100/100, `cohesion_share` 재계산 100/100, `top_category` 최다 유형(동점 포함) 100/100, 합 923, 유형별 합 = `category_totals`.
2. **상위 팬덤(결속문장수 순)** — 임영웅 30건(22.9%) · 김재중 25(32.5%, 결속비중 1위) · 박서진 25 · 정동원 24 · 김호중 22 · 이찬원 20 · 잭스키스 18 · 리센느(RESCENE) 18 …
3. **강조 3팬덤(KEY_FINDINGS 그대로)** — BTS 15건(6.6%, 대표유형 D) · 임영웅 30건(22.9%, 결속문장수 1위, A) · 리센느 18건(21.2%, D).
4. **카테고리별 평균 결속비중** — 원로그룹 0.169 > 트로트 0.165 > 솔로 0.108 > … > 힙합 0.059 > 록 0.042.
5. **LDA 결속형 비중과의 대조** — 동결 스냅샷(7,350건, K=10/M=5, 97개 공통 팬덤) Pearson r = 0.687 / Spearman ρ = 0.604;
   라이브 재적합(10,020건, 게이트 미통과) r = 0.274 / ρ = 0.079. 동결에서 dominant가 결속형인 팬덤은 김호중 1개.
   → 보고서 본문(동결) 해석 계층과는 방향이 일치하고, 게이트 미통과 라이브 재적합은 결속 신호를 거의 잡지 못한다.

## 한계

1. 유형별 키워드 전체 사전은 JSON에 없어 키워드 재매칭은 수행하지 않았다(광고 지수와 다른 점).
2. 키워드 지수와 LDA 비중은 계산 방식이 달라 5절 상관은 방향 일치 여부만 본다.
3. 동결·라이브 로스터 차이 3개 팬덤(한로로·pH-1·BE'O ↔ 몬스타엑스·투어스(TWS)·빈지노).
