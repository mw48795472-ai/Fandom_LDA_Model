# 국내 지역 지수(Domestic Regional Index) — 최종 코퍼스 10,020건 산출판

> 입력: `data/v7_final/fandoms_v3_100.json`(10,020건)과 동결 점수 JSON(표 15 대조용). 산출물: 이 폴더의 `domestic_regional_index_v7.json` / `.csv`.
> 실행 노트북: `domestic_regional_index_v7.ipynb`.

## 1. 방법론

```
RegionMentionCount(fandom, region) = 해당 팬덤 loyalty+spillover 근거문장 중 지역 키워드를 포함하는 불릿 수
RegionDiversity(fandom)            = n_regions_hit(검출된 서로 다른 지역 수) ÷ 17
```

| 지역 | 인정 키워드 |
|---|---|
| 서울·부산·대구·인천·광주·대전·울산·제주 | 지역명 그대로 |
| 세종 | `세종시`, `세종특별자치시` (세종문화회관 오매칭 방지) |
| 경기 | `경기도`, 수원, 성남, 부천, 안산, 화성, 의정부, 남양주 (일상어 "경기" 충돌 방지) |
| 강원 | 강원, 춘천, 강릉, 원주, 속초 |
| 충북 | 충북, 청주 |
| 충남 | 충남, 천안, 아산, 보령 |
| 전북 | 전북, 전주 |
| 전남 | 전남, 전라남도, 목포, 순천, 진도 |
| 경북 | 경북, 포항, 경주, 김천, 구미, 울릉 |
| 경남 | 경남, 창원, 진주, 김해, 거제, 남해 |

고양·여주·완주·동해·예산·정선처럼 일상어와 충돌하는 지명은 사전에서 제외한다. Member Mention Index와 같은 축소 구현 텍스트마이닝 지수이며,
Coverage Index의 market_coverage(해외 시장)와는 완전히 분리된 별도 지표다.

## 3. 보고서 표 15는 동결 스냅샷(7,350건) 값이다

분석보고서 표 15(지역 언급 상위 20개 아티스트)는 BTS 17건·5지역·서울 47%·다양성 0.29, 리센느 19건·경남 58%·0.29, 임영웅 28건·12지역·서울 21%·0.71을 적는다.
최종 10,020건에서는 20행 중 5행만 같고(임영웅·악동뮤지션·조용필·지드래곤·BTS), 대부분 값이 커졌다(god 16→28, 싸이 35→43, 리센느 19→22).
동결 스냅샷 코퍼스 파일은 저장소에 없지만, 병합이 팬덤별로 뒤에 덧붙는 구조이므로 각 팬덤의 loyalty/spillover **앞쪽 n건**(동결 점수 JSON의
`n_loyalty_bullets`/`n_spillover_bullets`, 97개 공통 팬덤 7,231건)으로 동결 코퍼스를 근사하면 **표 15의 20행 중 17행이 총언급·검출수·대표지역·비중까지 정확히 재현**된다
(나머지 이영지·영탁·로이킴은 1∼2건 차이 — 라운드 스왑·중복 제거로 앞쪽 n건 가정이 어긋난 흔적). 동결 근사에서 검출 지역 합은 410, 서울 비중은 35.1%다.

→ 보고서·KEY_FINDINGS의 국내 지역 값은 **동결 스냅샷 시점**이고, 이 폴더의 JSON은 같은 규칙을 **최종 10,020건**에 적용한 값이다.

## 5. 한계

1. 부분 문자열 매칭이라 "광주"(경기 광주시/광주광역시), "고성"(강원/경남) 같은 동음 지명은 구분하지 않는다. 감사(`REGIONAL_MENTION_TYPES_V7.md`, L17): 지역 언급 1,226건 중 배제 패턴(진도율·경주마·전주가 등)에 걸린 일반어는 2건, 광주 매치는 전부 광주광역시 문맥이라 경기 재배정 0건, 지명 문맥이 확인되는 것 755건, 문맥이 없어 불확실한 것 469건. 일반어를 뺀 엄격 지수로 바꿔도 대표 지역이 바뀌는 팬덤은 0개다.
2. 언급 0건은 "이 코퍼스에서 검출되지 않았다"는 뜻이지 지역 연고가 없다는 뜻이 아니다. 지역 연고(고향)와 지역 활동(투어·행사)을 구분하지 않고 합산한 1차 신호다. 문맥어로 나누면 활동 1,027(84%) / 연고 75(6%) / 기타 124이라 사실상 지역 활동 지수다(`domestic_regional_index_by_type_v7.csv`에 세 열로 분리).
