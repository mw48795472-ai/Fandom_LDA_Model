# 본문 언어 병행 판정 (L14) — 도메인 언어와 본문 언어는 얼마나 어긋나는가

세계 언어 지수의 언어는 출처 도메인 기준이다. 이 문서는 불릿 10,020건마다 본문 문자권·wordfreq 빈도로 언어를 따로 판정해 도메인 기준과 나란히 놓는다. 전부 `build_body_language_classifier_v7.py`가 만든다(외부 감지기 없음, 결정적).

## 0. 결론

- 도메인 언어(재구성 분류기)와 본문 언어가 같은 불릿은 4,934/10,020 (49.2%).
- 어긋남의 두 축: 한국 도메인인데 본문이 영어인 불릿 280건(한국 매체 영문판·영문 인용), 영어 도메인인데 본문이 한국어인 불릿 3,083건(해외 매체 한국어판·한국어 요약). 도메인 규칙이 없어 기본값으로 떨어진 불릿은 1,556건.
- 14개 외 언어 후보: 0건 (없음). 검출 언어 수는 하한이라는 한계 2의 크기가 이 정도다.
- **본문은 대부분 한국어다.** 본문 기준 한국어 불릿 8,463건(84.5%); 일본·중국·태국 등 외국 도메인 불릿도 본문은 한국어 요약이 대부분이라(도메인 ja 불릿 중 본문 일치 34/453) 본문 기준으로 바꾸면 세계 언어 지수 평균이 0.4795에서 0.1672로 무너진다. 즉 이 지수는 '본문 언어의 다양성'이 아니라 **'출처(도메인) 언어권의 다양성'** 이며, 수집 방식(근거를 한국어로 요약)상 본문 언어 판정은 지수를 대체할 수 없고 도메인 기준을 보완하는 보조 신호로만 쓸 수 있다. 문서·표의 지수명은 그렇게 읽어야 한다.
- 팬덤별 세계 언어 지수(엔트로피)의 상관: 저장값 ↔ 도메인 재구성 r = 0.9597, 저장값 ↔ 본문 기준 r = 0.5901. 본문 기준으로 바꾸면 순위가 얼마나 흔들리는지의 척도다.

## 2. 판정 방법

| 단계 | 규칙 |
|---|---|
| 문자권 | 한글·가나·한자·태국·키릴·아랍·라틴 글자 수의 최대. 가나가 있으면 한자도 일본어로 센다 |
| 라틴 | wordfreq zipf 평균으로 en/es/fr/id/vi/tl/pt/tr 비교, 최대 선택. 베트남어·튀르키예어 고유 자모 2개 이상이면 우선 |
| 14개 외 | 다른 라틴계 19개 언어 중 최대가 14개 최대보다 zipf 0.5 이상 높고 토큰 5개 이상이면 후보로 기록(`other_lang_candidate`) |
| 무 URL | 도메인 언어 ko(원본 규칙과 같음), 본문 판정은 그대로 |

## 3. 한계
1. 본문 판정은 문장 하나(짧으면 10여 단어)에 대한 빈도 비교라 라틴계 언어 간(특히 id/tl/pt/es)에는 오판이 있다. `body_margin`이 작은 행이 그 자리다.
2. 한국어 기사 안의 영문 고유명사(앨범명·차트명)는 라틴 글자 비중을 높이지만 한글이 더 많으면 ko로 판정된다. 영문이 절반을 넘는 혼합 문장은 라틴으로 넘어간다(`latin_letter_share`).
3. 지수 자체를 본문 기준으로 바꾸지는 않았다. 저장 JSON·README 표는 도메인 기준 그대로이고, 이 문서는 그 기준의 오차 크기를 보이는 병행 자료다.
