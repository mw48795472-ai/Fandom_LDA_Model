## 2. LDA 토픽모델링 → K→M→Persona→Loyalty/Spillover 4단계 해석 계층

| 계층 | 담는 질문 | 정의 |
|---|---|---|
| K (Topic) | 무엇을 하는가 | LDA 토픽 기반 배제 |
| F (Impact Pathway) | 어디로 전이되는가 | 팬덤 행동이 어떤 파급경로(F1∼F5)로 이어지는지, K→M=5 Meta Factor로 재매핑 |
| Persona | 이 팬덤은 어떤 방식으로 작동하는가 | 상위 2개 F 조합으로 정의되는 팬덤 작동 유형(통계적 재군집화가 아닌 사전정의 해석 계층) |
| Loyalty·Spillover | 얼마나 강한가 | 각 F 경로로 기여하는 강도를 loyalty_score·spillover_score의 F별 분해량으로 산출 |

### 2-1. K (원 토픽, 10개)

LDA(K=10, Latent Dirichlet Allocation, random_state=0)로 **동결 스냅샷 v7-40 시점 근거문장 7,350건**을 토픽화
(보고서 표 2-1: "K=10·M=5·실루엣=0.267 (근거 코퍼스 7,350건 시점)"; 4절 참고. 최종 라이브 코퍼스 10,020건의
재적합은 K=8·M=5·실루엣 0.046으로 게이트에 기각되어 해석 계층에 쓰지 않았다 —
`data/v7_final/lda_v6_diagnostics_live_reference_v7.json`. 동결 스냅샷 진단 원본은 `lda_v6_diagnostics_frozen_v7_40.json`:
K-grid 7개 중 K=10의 합성순위 합이 8로 최솟값, K=8은 9). 각 토픽은 φ분포 상위 4개 키워드를 그대로 조합해
자동 명명(재현 가능, 사람이 임의로 붙인 이름 아님). 아래 표의 명칭·F코드는 `data/v7_final/topic_cards_v7.json`(토픽별 상위 10개
키워드, 대표 불릿 3건, 대표 팬덤 5개 포함)과 동일하다. F코드 배정은 `Persona_결정공간.html`에 내장된
같은 스냅샷의 재적합 결과(`data/v7_final/persona_decision_space_v7.json`)와 10/10 일치한다. 토픽 명칭은 재적합
간 상위 키워드 순서가 일부 달라 HTML 쪽은 예컨대 K1 "해외현지보도형(보도·인도네시아·매체·무대)",
K9 "미디어크로스오버형(드라마·ost·영화·수상)"으로 표기된다.

| Topic | F코드 | 명칭(상위 키워드) |
|---|---|---|
| K0 | F5 | 음원차트기록형(기록·1위·차트·최초) |
| K1 | F3 | 동남아현지보도형(보도·매체·인도네시아·기사) |
| K2 | F4 | 예능방송출연형(예능·출연·mbc·sbs) |
| K3 | F5 | 일본오리콘앨범형(일본·빌보드·오리콘·판매) |
| K4 | F2 | 글로벌음반판매형(million·album·copies·chart) |
| K5 | F1 | 팬클럽공식기부형(공식·팬클럽·기부·콘텐츠) |
| K6 | F3 | 단독콘서트월드투어형(콘서트·투어·단독·월드투어) |
| K7 | F3 | 브랜드앰버서더형(브랜드·광고·앰버서더·매진) |
| K8 | F2 | 월드투어매진형(tour·concert·sold·world) |
| K9 | F4 | 영화드라마출연형(드라마·ost·영화·출연) |

### 2-2. F (메타요인, 5개) — K→M 계층적 재군집화

코사인거리(topic-word φ분포, L2 정규화 후) 기반 average-linkage 계층적 재군집화
(`sklearn.cluster.AgglomerativeClustering(metric="precomputed", linkage="average")`)로 K=10개 토픽을
M=5개 메타요인으로 재군집화. M은 후보 {5,6,7,8} 중 실루엣 계수 최댓값으로 선정(silhouette=0.267).

| F코드 | 명칭 | 구성 토픽 |
|---|---|---|
| F1 | 팬덤결속 경로 | K5 |
| F2 | 직접소비 경로 | K4, K8 |
| F3 | 현장경제 경로 | K1, K6, K7 |
| F4 | 산업전이 경로 | K2, K9 |
| F5 | 대중·글로벌확산 경로 | K0, K3 |

라벨링은 `LABEL_RULES`(8개 사전 정의 키워드 버킷: 결속형/소비력형/현장경제형/브랜드·상업형/차트·확산형/
미디어노출형/성과·수상형/해외매체·현지보도형)과 각 메타클러스터에 속한 토픽들의 통합 키워드 간 최다
overlap 매칭으로 자동 결정되며, 두 메타클러스터가 같은 버킷을 공유할 경우 특이 키워드를 덧붙여
라벨 유일성을 보장한다.

### 2-3. Persona (4유형) — F 조합 사전정의 매핑

각 팬덤의 상위 2개 F 경로 조합을 10개 사전정의 조합표(`persona_table_definition`)에 매칭
(`data/v7_final/fan_persona_v7.json`; 팬덤별 F1∼F5 비중은 `data/v7_final/fandom_scores_v6.csv` — 동결 스냅샷
7,350건 기준, activity 합 = 7,350):

| F 조합 | 페르소나 명 | 실현 여부(100개 팬덤 기준) |
|---|---|---|
| F1｜F2 | 핵심소비형 | 미실현 |
| F1｜F3 | 집단동원형 | **실현 (n=9)** |
| F1｜F4 | 브랜드동반형 | 미실현 |
| F1｜F5 | 글로벌결속형 | 미실현 |
| F2｜F3 | 원정소비형 | **실현 (n=17)** |
| F2｜F4 | 소비상업형 | 미실현 |
| F2｜F5 | 글로벌소비형 | 미실현 |
| F3｜F4 | 현장상업형 | **실현 (n=31)** |
| F3｜F5 | 글로벌투어형 | **실현 (n=43)** |
| F4｜F5 | 산업확장형 | 미실현 |

**핵심 발견**: 실현된 4개 페르소나 전부가 F3(현장경제 경로)를 공통 기반으로 공유한다. 즉 콘서트·투어 참여라는
"현장 소비"가 유형 분화의 출발점이며, 여기에 결합되는 두 번째 경로(F5 글로벌확산/F4 산업전이/F2 직접소비/
F1 결속)가 실제 유형을 가른다. 이는 "충성도가 파급효과로 전환되는 경로가 단일하지 않고 최소 네 갈래 이상으로
분화된다"는 연구의 핵심 주장을 뒷받침한다.

### 2-4. Loyalty × Spillover 2축 4구획

팬덤별 충성도 점수(loyalty_score)와 파급효과 점수(spillover_score)를 각각 표본 내 min-max 정규화(0∼1)한 뒤,
표본 평균을 기준선으로 4구획을 산출. **이 점수와 4구획은 라이브 코퍼스 10,020건 기준**이다(표본 평균 loyalty
0.3710 / spillover 0.2661; `data/v7_final/chart3d_payload_live_reference_v7.json`,
`fandom_scores_live_reference_v7.csv`). 아래 EvidenceScore 산식을 `fandoms_v3_100.json`에 그대로 적용하면 100개
팬덤 점수가 전부 재현된다(`verify_v7_final_consistency.py` [C]). 동결 스냅샷 산출 `fandom_scores_v6.csv`의
loyalty/spillover(예: BTS 0.931/1.000)는 같은 산식을 7,350건에 적용한 값이라 라이브 값(BTS 0.972/1.000)과 다르다:

| 구획 | 정의 | n |
|---|---|---|
| 핵심전략형 | 충성도·파급효과 모두 평균 이상 | 24 |
| 내부결속형 | 결속력은 높으나 파급력은 낮은 유형 | 17 |
| 외부견인형 | 파급력은 높으나 결속력은 낮은 유형 | 10 |
| 주변부 | 두 지표 모두 평균 이하 | 49 |

EvidenceScore(f) = Σ[1.0 + 0.5·n_num(t) + 0.3·n_kx(t)] — 충성도(Loyalty) 보너스 키워드 19종
(기부·돌파·매진·출범·창당·결성·총공·역사·지속·확장·1위·최초·신기록·밀리언셀러·팬클럽·팬카페·결속·충성·세대),
파급효과(Spillover) 보너스 키워드 18종(경제효과·매출·관광·지자체·앰버서더·모델·브랜드·팝업·협업·관중·방문·
상권·지역·홍보대사·수익·투어·콘서트·소비).

## 3. 강건성 검증

- **정규성**: Shapiro-Wilk 검정 → 충성도·파급효과 모두 p<.05로 정규분포 기각 → 순위 기반 검정 병행
- **상관**: Pearson r=0.493(p<.001, R²=0.243, 설계 기준 |r|<0.5 충족) / Spearman ρ=0.380(p<.001, 방향·유의성 일치)
- **다중회귀+VIF** (편상관 대체): factor_diversity ∼ loyalty_score + spillover_score 등 구조. 활동량(근거
  코퍼스 수) 추가 통제 시 R²=0.243→0.847로 설명력 급증, 충성도 회귀계수가 -0.200(p<.001)으로 부호 반전
  → 트레이드오프 관계 시사. VIF=1.93 (경험적 기준 5 미만, 다중공선성 문제 없음)
- **4분면 독립성**: 2×2 카이제곱(Yates 보정) χ²=8.3439, dof=1, p=0.003869 → 두 축 독립 가정 기각, 4구획 구조
  유의미 (라이브 코퍼스 기준. 프로즌 스냅샷 기준은 χ²=10.2273, p=0.0013837). **주의**: 이 검정의 2×2표는
  `positioning_map_correlation_live_v7.json`에 기록된 대로 loyalty·spillover 각각 **0.5 초과 여부**로 나눈
  [[7,17],[4,72]](동결 CSV는 [[8,17],[4,71]])이며, 2-4절의 표본 평균 기준 4구획(24/17/10/49)과는 기준선이 다르다.
  평균 기준 4구획표로 계산하면 χ²=16.84(p<.001)로 결론(독립 가정 기각)은 같지만 값이 다르므로, 두 "4분면"을 혼동하지
  말 것. (3절의 통계는 전부 라이브 점수로 재현됨 — `verify_v7_final_consistency.py` [D])
- **영향점 진단**: Cook's Distance 상위 — BTS(0.5749, 최댓값) > god(0.284) > 이효리(0.2538) > TWICE(0.2315)
  > BLACKPINK(0.094). 임계값(4/n=0.04) 초과
- **민감도 분석**: 하이라이트 팬덤 제거 시 상관 유지 — BTS 제외 r=0.4314(p=8.27e-6), 임영웅 제외
  r=0.4761(p=6.34e-7), 리센느 제외 r=0.4932(p=2.14e-7)
- **Leave-one-out**: 최대 |Δr|=0.0618(BTS), 평균 |Δr|=0.00516 — 특정 팬덤 하나에 결과가 좌우되지 않음

## 4. 실루엣 게이트 거버넌스 (K→M 재군집화 불안정성 대응)

리서치를 보강하며 코퍼스가 성장해도(라운드별 변화 1% 미만 단위) K→M 재군집화 결과가 예측불가능하게
바뀌는 현상이 여러 라운드에 걸쳐 반복 관찰되었다(여러 K 토픽이 하나의 메타요인으로 뭉치거나 흩어짐).
이를 통계적으로 "해소"하려 하지 않고, 아래와 같은 거버넌스 규칙으로 대응했다.

1. **실루엣 게이트**: 새 K→M 재군집화 결과가 기존 채택 스냅샷의 실루엣 계수를 넘지 못하면 자동 기각.
   매 라운드 실제 재계산값만 사용(센티널 값 금지).
2. **동결 스냅샷**: 검증된 v7-40 스냅샷(7,350건, K=10, M=5, silhouette=0.267)을 해석 계층(토픽 명명·F
   배정·페르소나 분류)의 고정 기준선으로 삼는다.
3. **이원 구조**: 라이브 코퍼스는 별도 트랙으로 계속 증량하되, 보조지표(7개 지수) 계산에만 반영하고
   해석 계층에는 반영하지 않는다.
4. **정직한 한계 기록**: v7-41∼v7-65 재적합 라운드가 전부 기각됨(누적 26회 연속, 가장 최근 v7-65 라운드
   silhouette=0.141 < 기준 0.267)을 숨기지 않고 그대로 보고서 본문에 명시했다. 최종 라이브 코퍼스 10,020건
   시점의 참고 재적합도 K=8·M=5·silhouette=0.046으로 기각분이며, 그 진단값(K-grid 포함)은
